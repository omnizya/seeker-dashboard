# Auth & Onboarding Design Resources

## Knowledge

- [RefactoringUI — Design System Tips](https://refactoringui.com/)
  Practical, opinionated guide to building cohesive design systems without a dedicated designer. Use for: spacing, color, typography decisions in the token system.

- [Laws of UX](https://lawsofux.com/)
  Collection of UX psychology principles with practical applications. Use for: progressive disclosure, Hick's Law, Fitts's Law applied to auth forms.

- [Material Design 3 — Dark Theme Guidelines](https://m3.material.io/styles/dark-theme)
  Google's dark theme best practices — surface colors, elevation, contrast. Use for: the near-black blue background system and accessible contrast ratios.

- [WCAG 2.2 Quick Reference](https://www.w3.org/WAI/WCAG22/quickref/)
  Official accessibility guidelines reference. Use for: verifying AA compliance on color contrast, focus states, keyboard navigation.

- [Duolingo Design System](https://design.duolingo.com/)
  Duolingo's public design principles — gamification mechanics, character design, progress systems. Use for: understanding how gamification layers onto learning.

- [Stripe Press — Designing for Trust](https://press.stripe.com/)
  Stripe's approach to communicating security and reliability through design. Use for: trust indicators, security messaging in auth flows.

- [The Refactoring UI Book — Adam Wathan & Steve Schoger](https://www.refactoringui.com/book)
  Color palette creation, typography scale, spacing systems, and visual hierarchy. Use for: token system architecture decisions.

- [Headspace Brand Guidelines (case study)](https://www.headspace.com/brand)
  Headspace's visual identity — how they communicate calm, care, and science simultaneously. Use for: balancing warmth with premium feel in the auth experience.

- [Arabic Typography Basics — IBM](https://www.ibm.com/design/language/typography/arabic/)
  Guidelines for Arabic type: baseline differences, diacritics, RTL layout challenges. Use for: ensuring the Arabic-first auth design respects typographic standards.

- [Next.js Internationalization (i18n) — App Router](https://nextjs.org/docs/app/building-your-application/routing/internationalization)
  Official Next.js RTL/i18n routing patterns. Use for: implementing Arabic routing and RTL layout switching.

## Wisdom (Communities)

- [r/UXDesign](https://reddit.com/r/UXDesign)
  Professional UX discussion. Best for: feedback on auth flow wireframes, accessibility questions.

- [refactoring-ui Discord](https://discord.gg/refactoringui)
  Community around the Refactoring UI book. Good for: design system and visual design feedback.

- [Tailwind CSS Discord](https://tailwindcss.com/discord)
  Active Tailwind community. Use for: shadcn/ui customization, dark mode patterns, RTL tailwind utilities.

## Gaps

- No comprehensive resource found specifically on **esoteric/spiritual SaaS design patterns** — this is the creative frontier the teaching sessions will explore.
- No centralized reference for **gamified Arabic-first learning platform UX** — existing Arabic edtech platforms generally do not share design patterns publicly.
