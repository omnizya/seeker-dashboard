ربط الرموز Mapping Design Tokens → shadcn/ui CSS Variables

هذا هو المفتاح. نظام ألوان shadcn/ui يعمل بمتغيرات CSS بتنسيق HSL. سنأخذ لوحة الألوان من المواصفات ونحولها إلى قيم HSL مناسبة.

🎯 لماذا HSL؟

shadcn/ui تستخدم HSL ( Hue, Saturation, Lightness ) بدلاً من HEX لأن HSL تسمح بتعديل الشفافية والسطوع بسهولة عبر hsl(var(--primary) / 0.8). هذا هو أساس نظام التظليل (theming) في shadcn/ui.

① تحويل الألوان من HEX → HSL

RTL تنفيذ Arabic-First Implementation

منصة الباحث عربية من الجذور. هذا ليس مجرد dir="rtl" — إنه قرارات تصميمية تبدأ من اليمين.

⚠️ أهم مشكلة RTL واجهتها

في تخطيط الشاشة المنقسمة، اللوحة اليسرى (المحتوى) ستكون على اليمين في RTL. اللوحة اليمنى (النموذج) ستكون على اليسار. هذا عكس تخطيط Linear/Notion — لكنه صحيح للعربية.

قواعد RTL في Tailwind

/* RTL Utilities — يجب إضافتها */ // 1. تأكد من أن tailwind.config.ts يفهم الاتجاه // أضف هذا الإعداد: export default { // ... باقي الإعدادات future: { hoverOnlyWhenSupported: true, }, // لا يوجد خيار rtl مباشر — نستخدم كلاسات يدوية } // 2. في المكونات، استخدم كلاسات شرطية <div className="rtl:text-right ltr:text-left" /> // 3. للأيقونات: تظهر يمين النص في RTL <span className="inline-flex items-center gap-2"> <Icon className="rtl:order-last" /> // الأيقونة على اليمين <span>النص</span> </span>

الحركة والتفاعل Motion & Interaction Specifications

الحركة ليست ديكوراً — إنها دلالة. تخبر المستخدم من أين أتى وإلى أين يذهب.

⏱ جدول التوقيت

التفاعل المدة Easing
زر CTA — hover/active 150ms ease-out
بطاقة اختيار — toggle 200ms ease-out
الانتقال بين خطوات التسجيل 300ms ease-in-out
ظهور قائمة الميزات (stagger) 50ms بين كل عنصر ease-out
إنجاز XP (أرقام متحركة) 800ms spring (stiffness 100)
توهج البطاقة المختارة (glow) 1000ms ease-in-out (loop)
إخفاء Toast 400ms ease-in

🎬 مثال: حركات Framer Motion للخطوات

// AnimatePresence للانتقال بين خطوات التسجيل <AnimatePresence mode="wait"> <motion.div key={currentStep} initial={{ opacity: 0, x: 50 }} // يظهر من اليسار ← (لأن RTL) animate={{ opacity: 1, x: 0 }} exit={{ opacity: 0, x: -50 }} // يختفي إلى اليمين ← transition={{ duration: 0.25, ease: "easeInOut" }} > {renderStep(currentStep)} </motion.div> </AnimatePresence> /* ملاحظة: في RTL، اليسار واليمين معكوسان. لكن Framer Motion يستخدم CSS translate, لذا نفس القيم تعمل بشكل طبيعي مع dir="rtl" */
🔑 مبدأ أساسي في الحركة

احترم prefers-reduced-motion. أضف هذا الشرط في كل motion component:

if (window.matchMedia('(prefers-reduced-motion: reduce)').matches) { skipAnimations(); }

الحركة تحسن التجربة — لكنها لا يجب أن تمنع الوصول أبداً.
